# 2026-09-03 小白车静态部署说明

本包用于低于 10 km/h、园区无交通信号灯路线的 DISARMED 验收。所有数值均
先写入源码树、重新编译，再进入运行环境。部署前已保留原文件快照。

## 部署范围

- 三颗 BPearl：沿用已经通过多求解器静态重复性验证的原值。
- 普通 USB 相机前左、前右、后左、后右：沿用上次静态重复性值。
- 普通 USB 相机前中、后中：按用户要求作为固定记录传感器写入静态 TF；它们
  不进入当前 Autoware 感知决策。保留上一次静态估计，不采用跨日不一致的新修正。
  新候选的跨日差分别为 54.455 mm/0.5219 deg 和 25.886 mm/1.5182 deg，不能
  称为精密外参。
- 交通灯相机：采用物理位置合理的旧静态多变体共识，而不采用 Part-4 中偏离
  机械位置 512.6 mm 的退化解。当前只保证 TF 和记录完整，不允许将其用于有灯
  道路决策。
- 鱼眼相机：不进入 Autoware 活动 TF；BEV 使用任务 D 的独立相对地平面配置。

## 健康门策略

硬门限：关键进程存在、CAN/车辆接口两层均为 DISARMED、四雷达融合点云、IMU
原始数据、GNSS 原始数据、超声波和底盘反馈均至少到达一帧。

提示项：交通灯相机、RTK FIX、`map -> base_link` 定位初始化。它们在当前无灯、
可能无卫星信号的静态测试中不阻断启动，但诊断仍显示 WARN/ERROR，便于操作员
发现问题。

## 安全边界

六小时静态测试强制 `WHITE_CAN_TX_ENABLED=false`，并每分钟检查两层 armed
话题。任一层变为 true 或主启动进程退出，测试立即停止并调用 `stop.sh`。

本包不包含空地上的纵向、制动、转向试验结果；对应试验必须在封闭场地、地面
车轮承载状态下单独完成。
