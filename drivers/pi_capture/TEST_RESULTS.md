## 语音与 CAN

- `w102-vehicle-io.service` 已移除 `network-online.target` 和固定 IP 等待程序。
- 配置 API 改为绑定 `0.0.0.0`，没有网线时不再因 `192.168.1.186` 尚未出现而启动失败。
- 服务重启后 8 秒内收到 5,746 帧 CAN，接口 `can11`，只读状态正常。
- CAN 控制模式为遥控时，语音管理器立即选中并尝试播放 `remote` 事件。
- 验收时 USB 声卡未连接，ALSA 返回 `No such device`；这是硬件缺席状态，不是 CAN 触发或语音调度失败。

## 图传模式

- 默认/恢复 `bev`：接收 10.0 Hz，发送约 10.0 Hz，四路新鲜掩码 `15`。
- `raw-all`：四路分别约 9.78–9.95 Hz，输出确认掩码 `0x000F`。
- `front`：前路 10.0 Hz，其余三路 0 Hz，输出确认掩码 `0x0001`。
- 单路模式下，未选中的旧图像 HTTP 接口在 1 秒后返回 503，避免误用缓存帧。
- `bev`、`raw-all`、`front` 之间的切换均收到树莓派带相同 nonce 的确认。
- 模式切换只影响当前进程；服务重启后已验证自动恢复 `bev`。
