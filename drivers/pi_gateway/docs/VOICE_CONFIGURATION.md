# 语音配置和离线 TTS

树莓派根据 CAN 状态独立决定何时播报；即使工控机断开，已有配置仍会工作。工控机只用于修改配置和生成可编辑的离线中文 WAV。

在 `http://127.0.0.1:8086/` 点击“语音设置”可修改：

- 音源：树莓派原系统录音，或可编辑中文神经语音。
- 五个优先事件：倒车、左转、右转、自动驾驶、遥控驾驶。优先级从左至右递减。
- 每个事件的启用、文字和重复间隔。间隔就是唯一的重复频率控制，不会与另一个频率叠加。
- 20 个角色参数、语速、播放倍率、请求音量、最高音量上限和一键静音。
- 固定测试中文 MP3，用于排除 USB 声卡、功放和喇叭故障。

生产快照位于 `config/pi-vehicle-io-current.json`。网页通过 `http://192.168.1.186:8089` 读取/下发；神经语音在工控机离线生成并上传到 Pi，Pi 不需要 Piper 或外网。

## 模型与完整性

- `zh_CN-huayan-medium.onnx`：生产默认女声基础模型。
- `zh_CN-chaowen-medium.onnx`：保留的第二套中文基础模型。
- `voice/requirements.lock`：Piper/ONNX 精确依赖版本。
- `voice/SHA256SUMS`：两套模型、配置和测试音校验值。

切换基础模型：

```bash
./configure.sh --set PIPER_MODEL_NAME=zh_CN-chaowen-medium.onnx --restart
```

Piper 模型进程为长驻进程，合成结果缓存到 `runtime/voice-cache/`。文字、角色或语速改变会产生新的缓存键；该目录可在服务停止后清理，不应提交 Git。

Huayan 模型卡标注源数据集许可未知。工程内保留模型用于当前离线部署，但公开或商业再分发前必须完成许可审查。
