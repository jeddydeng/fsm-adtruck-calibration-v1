# 树莓派相机工控机接收端（标定仓库版）

本目录是 FSM-Pi-Master 接收端的源码子集，不是原来的独立生产安装包。
统一安装和使用说明以仓库根目录 [README](../../README.md) 和
[英文操作手册](../../docs/OPERATIONS_EN.md) 为准。

从仓库根目录启动（前台运行，Ctrl+C 停止）：

```bash
./scripts/start_pi_receiver.sh fisheye
./scripts/start_pi_receiver.sh traffic  # 另一个终端，仅在没有既有 ROS 图像来源时运行
```

联合外参入口 `./start_joint.sh` 默认按需启动鱼眼接收端；它只关闭自己启动的进程。
交通灯接收端默认不会自动启动，避免重复 ROS 发布；需要时设置
`CALIBRATION_AUTO_TRAFFIC=1`。已有接收服务可继续复用。

| 通道 | 工控机监听 / 树莓派控制端口 |
|---|---|
| 四鱼眼与 BEV | UDP 5610 / 5611 |
| 交通灯相机 | UDP 5620 / 5621 |
| 鱼眼网页与 SDK | TCP 127.0.0.1:8086 |
| 交通灯网页 | TCP 127.0.0.1:8090 |

默认树莓派地址 192.168.1.186，工控机传感器网卡地址 192.168.1.102/24；
不要给该专用网卡配置默认网关。修改前核实实际网络拓扑。

保留了相机传输、分片重组、断线恢复、网页和 ROS 图像接收的依赖源码。
未包含语音模型、大型语音资源、原独立安装器、开机服务及桌面自启动配置。
语音与车辆 I/O 页面不是本标定仓库的验收范围，不要用它们控制车辆。

协议参考：[四鱼眼](docs/CAMERA_STREAM_API.md)、[交通灯](docs/TRAFFIC_CAMERA_API.md)。
`docs/` 中其余文件是原生产包历史记录；其中旧安装器、服务名、语音资源和
验收结果不代表本仓库已安装或复测这些功能。
